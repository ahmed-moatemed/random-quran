# Random Quran Verse Generator 📖

تطبيق بسيط يعرض آية عشوائية من القرآن الكريم في كل مرة، مع نص عربي واضح وتجربة قراءة مريحة.  
يعتمد على **Quran API** لجلب الآيات ويعمل بتصميم متجاوب يناسب جميع الأجهزة.

## 🚀 Features
- عرض آية عشوائية من القرآن الكريم  
- نص عربي واضح وسهل القراءة  
- جلب البيانات من Quran API  
- زر لتحديث الآية المعروضة  
- تصميم بسيط وهادئ مناسب للقراءة  
- Responsive Design يعمل على جميع الأجهزة

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**  
- **Fetch API**  
- **Quran API**  
- **Responsive Design**
